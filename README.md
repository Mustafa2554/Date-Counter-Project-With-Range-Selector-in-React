
# Date-Counter-Project-With-Range-Selector-in-React 📅

A React-based date counter that allows users to control the number of days using a range slider.

## ✨ Features

- Range slider to select step values from 1 to 7.
- Increase and decrease the count using `+` and `-` buttons.
- Date updates according to the selected step.
- Displays the weekday, month, day, and year.
- Automatically handles month and year changes.
- Count cannot go below 0.
- Step cannot go below 1.
- Modern dark-themed UI.

## 🛠️ Technologies Used

- React
- JavaScript
- HTML5
- CSS3
- Vite

## ⚙️ How It Works

1. Use the range slider to select the step value.
2. Press `+` to increase the count and move the date forward.
3. Press `-` to decrease the count and move the date backward.
4. Changing the step alone does not change the date.
