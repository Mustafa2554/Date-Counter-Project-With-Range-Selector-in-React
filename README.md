# React Date Counter 📅

A simple and interactive Date Counter built with React. Adjust the step using a range slider and move dates forward or backward with the count buttons.

## 🚀 Live Demo

**Live Website:** [View Live Demo]()

## ✨ Features

- **Range Slider:** Adjust the step value from 1 to 7.
- **Dynamic Date Counter:** Increase or decrease the count to change the date.
- **Step-Based Date Calculation:** Each count action moves the date by the selected step.
- **Minimum Limits:** Step cannot go below 1, and count cannot go below 0.
- **Automatic Date Updates:** Handles day, month, and year transitions automatically.
- **Dark Theme UI:** Clean, modern, and responsive design.

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## ⚙️ How It Works

1. Move the range slider to select a step value.
2. Click the `+` button to increase the count and move the date forward.
3. Click the `-` button to decrease the count and move the date backward.
4. Changing the step alone does not change the date.
5. The count cannot go below zero, and the step cannot go below one.
